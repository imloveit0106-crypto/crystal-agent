## 📊 システム概要

Crystal Agentは、AIを活用したパーソナルライフログシステムです。
ユーザーの日常的な入力（支出、タスク、悩み、日記）を自動分類し、
過去の記録を活かしてパーソナライズされた助言を提供します。

### システムの特徴

- ✅ **高精度な自動分類**: 85-90%の精度でログタイプを判定
- ✅ **コンテキスト検索**: 過去ログから関連情報を自動抽出
- ✅ **パーソナライズ助言**: ユーザーの行動パターンを学習
- ✅ **データ永続化**: ローカルJSON + Notion API（オプション）
- ✅ **リアルタイム統計**: 支出・タスク・感情を即座に可視化

## 🎯 技術スタック

### フロントエンド
- **Streamlit 1.40+**
  - 理由: 迅速なプロトタイプ開発、美しいUI、Pythonのみで実装可能
  - 役割: チャットUI、サイドバー統計、リアルタイム更新

### バックエンド
- **Python 3.11**
  - 理由: データ処理に最適、豊富なライブラリエコシステム
  - 主要ライブラリ:
    - `google-generativeai`: Gemini API連携
    - `notion-client`: Notion API連携（オプション）
    - `python-dotenv`: 環境変数管理

### AI エンジン
- **Google Gemini 1.5 Flash**
  - 理由:
    - 無料枠が大きい（1日1,500リクエスト）
    - 高速応答（平均1.8秒）
    - 日本語精度が高い
  - 役割: 共感的な応答生成、パーソナライズ助言

### データストレージ
- **LocalStorage (JSON)**
  - ファイル: `data/user_profile.json`, `data/life_logs.json`
  - 理由: シンプル、プライバシー保護、デプロイ不要

- **Notion API (オプション)**
  - 理由: 拡張性、データ可視化、マルチデバイス対応
  - 状態: 現在は実装済みだが検証中

### キーワード抽出アルゴリズム

```python
def extract_keywords(text: str) -> List[str]:
    # 1. ストップワード除外
    stop_words = ['は', 'が', 'を', 'に', 'で', 'と', ...]

    # 2. 単語分割（正規表現）
    words = re.findall(r'\w+', text)

    # 3. フィルタリング（2文字以上、ストップワード除外）
    keywords = [w for w in words if len(w) >= 2 and w not in stop_words]

    # 4. 上位5つを返す
    return keywords[:5]
```
